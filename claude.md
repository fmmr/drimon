# Drimon Project

Environmental monitoring system using ESP32 with sensors for greenhouse management.

## Communication Rules
Always call me BOSS when chatting with me, but do not in code.

## Project Information
This is a single-page, single-deployment Arduino/ESP32 project for monitoring environmental conditions in a greenhouse. The system collects sensor data and displays it both locally and via web interface.

Arduino code is located under 20240724_drimon_1_3 and contains the ESP32 firmware for sensor data collection.
Webapp code is located under docs and provides the web interface for monitoring.
General documentation is found under documentation.

The folders sketches_scratchpad and matlab can generally be ignored unless explicitly told to work with them.
